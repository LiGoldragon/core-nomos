# d47 Compatibility Fixtures

These fixtures freeze the production graph before the authored algebra grows.
Their source revisions are:

- `core-nomos` `d47e1e4441b7110051aba0f54eb6dea31c057b4c`
- `signal-nomos` `40ea24045194542a679b97ae34e53c92c2393480`
- `nomos-engine` `0773e03eae899e1364cb639280e57520d6d454b2`

The later baseline commits add only tests and these fixtures. `jj diff` from
the revisions above verifies that production source and dependency locks were
unchanged when the generators ran.

The Capsule, projection, legacy Deploy request, and Redb state were generated
by `nomos-engine/tests/freeze_d47.rs` with:

```sh
FREEZE_D47_WORKSPACE=/git/github.com/LiGoldragon \
  cargo test --test freeze_d47 -- --ignored
```

The individual enum archives and the real Named declaration containing an
Invoke were generated by `core-nomos/tests/freeze_d47.rs` with:

```sh
FREEZE_D47_CORE=/git/github.com/LiGoldragon/core-nomos \
  cargo test --test freeze_d47 -- --ignored
```
